# Iris Dataset Analysis

## Problem / Research Question
Can we distinguish Iris flower species based on their sepal and petal measurements?

## Dataset Source and Permissions
- **Source:** UCI Machine Learning Repository (Iris Dataset), loaded via `seaborn`
- **Permissions:** Public Domain (CC0). Free to use, modify, and distribute.

## Methods and Tools
- **Language:** Python
- **Libraries:** pandas, matplotlib, seaborn
- **Approach:** Exploratory Data Analysis (EDA) and data visualization.

## Key Findings and Limitation
- **Finding:** Petal length is a strong distinguishing feature between the three Iris species (setosa, versicolor, virginica).
- **Limitation:** The dataset contains only 150 samples, which is very small and may not generalize to real-world field data.
